# Simple Interest Calculator

A small Bash project that calculates simple interest from user-provided principal, annual rate of interest, and time period.

## Inputs
- Principal amount
- Annual rate of interest (percent)
- Time period (years)

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Run
```bash
bash simple-interest.sh
```

## Project
This repository contains a simple-interest calculator implemented in Bash as part of a Git and GitHub learning project.
